PACWP Classifieds - Craigslist for WordPress

A complete classified ads solution that brings Craigslist-style functionality to your WordPress site.

Key Features

  • Custom post type for classified listings
  • Categories and location taxonomies
  • Frontend submission form for users
  • Search and filtering functionality
  • Admin approval system
  • Contact information integration
  • Responsive Craigslist-style design
  • SEO-friendly URLs and structure

How to Display Listings

Use these shortcodes to display listings on any page or post:

[pacwp_listings]

Shows all listings with default settings

[pacwp_listings category="cars-trucks" limit="10"]

Shows 10 listings from the "cars-trucks" category

[pacwp_listings location="new-york" limit="5"]

Shows 5 listings from New York

User Submission Form

Allow users to submit their own listings:

[pacwp_submit_form]

This creates a complete submission form with all necessary fields including title, description, category, location, price, and contact information.

Search and Filter

Add search functionality to your listings:

[pacwp_search_form]

Creates a search form with category and location filters

[pacwp_search_form show_categories="false"]

Search form without category dropdown

Default Categories

The plugin comes with pre-configured categories similar to Craigslist:

  • For Sale: cars-trucks, electronics, furniture, general
  • Housing: apartments-housing, rooms-shared, housing-wanted
  • Jobs: accounting-finance, admin-office, art-media-design, general-labor
  • Services: automotive, beauty, computer, household
  • Community: activities, artists, childcare, general

Installation Instructions

  1. Upload the plugin files to /wp-content/plugins/pacwp-classifieds/
  2. Activate the plugin in your WordPress admin
  3. Create pages for listings, submissions, and search
  4. Add the appropriate shortcodes to each page
  5. Customize the appearance with CSS if needed

Admin Features

  • Manage all listings from WordPress admin
  • Approve or reject pending submissions
  • Edit listing details and contact information
  • Manage categories and locations
  • View submission statistics
